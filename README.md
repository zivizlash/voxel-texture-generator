# Процедурный генератор текстур 16x16

Легковесный процедурный генератор пиксельных текстур (16x16) для воксельных игр, тайловых движков и 2D/3D песочниц. Написан на чистом **Node.js** без внешних зависимостей.

Генератор создает бесшовные текстуры материалов с естественным попиксельным распределением цветов, псевдообъемным освещением и поддержкой воспроизводимых сидов.

---

## Ключевые возможности

- **Чистый Node.js (Zero-Dependency):** встроенная сборка валидных `.png` файлов через модуль `node:zlib`. Не требует установки сторонних пакетов (`npm install` не нужен).
- **Детерминированность:** генератор псевдослучайных чисел (Mulberry32) гарантирует точную повторяемость результатов по заданному сиду.
- **Математическая бесшовность (Tiling):** все алгоритмы шума (fBm, Worley, клеточный шум) зациклены тороидально по модулю 16, что обеспечивает идеальную стыковку тайлов со всех сторон.
- **Ограниченные палитры (4–7 тонов):** гармоничные, приглушенные оттенки с цветовым сдвигом (hue shifting) для естественной передачи теней и бликов.
- **Попиксельное распределение и дизеринг:** матрица Байера (4x4) и высокочастотный микрошум исключают появление плоских однотонных «островков», создавая характерную зернистость ретро-спрайтов.
- **Псевдообъемное освещение:** верхний и верхне-левый направленный свет высветляет верхние кромки рельефа и затемняет углубления.
- **Генерация вариантов:** каждый блок генерируется сразу в 5 уникальных вариациях (110 текстур за прогон).
- **Датированные прогоны:** каждый запуск автоматически сохраняется в отдельную папку с текущей датой и временем.
- **Интерактивная HTML-витрина:** просмотр текстур в масштабе 600% со встроенным инспектором тайлинга 3x3 для мгновенной проверки стыков.

## Поддерживаемые материалы

В базовый каталог входят **22 типа материалов**, разделенных по 6 категориям физической формы:

| Категория | Материалы | Особенности шаблона |
|---|---|---|
| **Сыпучие** | Песок, Красный песок, Гравий | Высокочастотный зернистый шум, микро-гранулы, мягкие дюнные перепады |
| **Глина и терракота** | **Глина**, **Терракота** | Пластичные деформации осадочной глины, шелковистая гладь и матовая обожженная керамика |
| **Органика** | Грязь, Каменистая земля, Укоренившаяся земля, Подзол, Мицелий | Рыхлая почва, прожилки корней, каменистые включения, споры и хвойный опад |
| **Камни и кладка** | Камень, Андезит, Гранит, Диорит, **Булыжник**, **Кирпич** | Угловатые сколы Voronoi, кладка булыжников с глубоким швом, перевязка кирпича |
| **Слоистые** | Песчаник, Красный песчаник, Глубинный сланец | Горизонтальные пласты, волны сланцеватости, теневые швы и ступени |
| **Древесина** | **Доски**, **Дерево (бок)**, **Дерево (срез)** | Продольные волокна, настил досок с гвоздями, годичные кольца на торцах |

> [!NOTE]
> **Кирпич (`bricks`)** имеет выраженную перевязку кирпичной кладки (running bond) 16x16: 4 горизонтальных ряда, шахматное смещение швов на 4 пикселя, углубленные цементные швы и верхние/левые освещенные фаски.
>
> **Текстуры дерева** состоят из двух согласованных процедурных текстур:
> 1. `wood_log_side` — боковая кора с вертикальными бороздами, волокнами и продольными трещинами.
> 2. `wood_log_top` — срез (торец) ствола для верха и низа блока с концентрическими годичными кольцами, искривленными через Domain Warping, центральной сердцевиной и защитной каймой коры.

## Быстрый старт

### Требования
- Установленный **Node.js** версии 18 или новее (для CLI и локального сервера).

---

### Вариант 1: Интерактивное веб-приложение (в браузере)

Вы можете генерировать текстуры **на лету прямо в браузере**, вводя произвольные сиды:

1. **Запуск локального сервера:**
   ```bash
   npm start
   ```
   Откройте [http://localhost:3000](http://localhost:3000) в браузере. Либо просто откройте файл `index.html` двойным кликом в проводнике.

2. **Возможности веб-интерфейса:**
   - **Поле ввода сида (Seed):** вводите любое число или текстовую строку (например: `4242`, `desert`, `amethyst`).
   - **Кнопка «🎲 Случайный» (горячая клавиша `R`):** мгновенно выбирает случайный сид и генерирует набор.
   - **Выбор количества вариантов:** 3, 4, 5, 6 или 8 вариаций для каждого материала.
   - **Кнопка «⚡ Сгенерировать» (горячая клавиша `Enter`):** мгновенная генерация всех текстур (все 80 текстур генерируются за 10–20 мс прямо в памяти браузера через Canvas API).
   - **Панель «⚙️ Параметры шума» (fBm, Domain Warping, Shading):**
     - **Октавы fBm (1–6):** сложение октав с разной частотой и амплитудой (1-я октава: крупные пятна, 2-я: вмятины, 3-я: мелкая рябь, 4+: пористость).
     - **Domain Warping (0.0–2.0):** искажение сетки координат через шум (создает естественные завихрения, потеки, кольца и мраморные жилы).
     - **Масштаб частоты шума (0.5x–2.0x):** плотность координатной сетки.
     - **Дизеринг Байера (0.0–2.0):** сила зернистости для ликвидации плоских пятен.
     - **Рельефный свет (0.0–2.0):** верхний направленный псевдообъем.
     - **Пресеты в 1 клик:** 🌿 *Стандарт*, 🌊 *Завихрения*, 💎 *Кристалл*, ☁️ *Мягкий*, 🕹️ *Ретро 8-бит*.
   - **Выбор вариантов (галочки):** возле каждого варианта расположен интерактивный чекбокс для добавления текстуры в атлас. Доступны быстрые кнопки: «✓ Все», «✕ Снять», «⭐ 64 шт» (для точной сетки 8×8) и «1️⃣ По 1 шт».
   - **Кнопка «🗺️ Преобразовать в атлас»:** собирает все отмеченные варианты в единый текстурный атлас 8×8 блоков (128×128 пикселей).
   - **Окно предпросмотра атласа:** интерактивный просмотр с масштабированием (200%, 400%, 600%), переключением сетки блоков 8×8 и отображением информации о слоте при наведении курсора.
   - **Кнопка «💾 Сохранить .png с выбором пути»:** использует стандартный системный диалог File System Access API для сохранения атласа в выбранную папку с произвольным именем файла (с резервным скачиванием для неподдерживаемых браузеров).
   - **Инспектор бесшовности (3x3 Тайлинг):** кликните на любую текстуру, чтобы проверить стыковку тайлов, включить сетку или скачать отдельный PNG 16x16.
   - **Скачивание вариантов блока:** кнопка `⬇` в заголовке каждого материала позволяет выгрузить все сгенерированные варианты.

---

### Вариант 2: Запуск пакетной генерации через CLI

1. **Стандартный запуск** (сид по умолчанию `1337`, по 5 вариантов на блок):
   ```bash
   node generate.js
   ```

2. **Запуск с произвольным сидом и параметрами шума:**
   ```bash
   node generate.js --seed 4242 --octaves 4 --warp 1.2 --scale 1.0 --dither 1.2 --light 1.1
   ```

3. **Запуск с изменением количества вариантов:**
   ```bash
   node generate.js --seed 9999 --variants 8 --octaves 5
   ```

## Результаты CLI генерации

Каждый запуск через `node generate.js` формирует изолированный каталог по пути:
```
output/YYYY-MM-DD_HH-mm-ss/
├── textures/
│   ├── stone_var1.png
│   ├── stone_var2.png
│   └── ... (всего 110+ файлов .png)
└── index.html                 # Интерактивная витрина с проверкой тайлинга
```

Файл `index.html` в папке прогона также оснащен встроенным движком генерации: вы можете открыть его и продолжить генерировать новые сиды прямо в нём!
